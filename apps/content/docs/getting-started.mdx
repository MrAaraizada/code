# Getting Started

Welcome to our design system! This guide will help you get up and running quickly.

## Installation

```bash
npm install @repo/library
```

## Usage

Import components from the library:

```tsx
import { Button } from "@repo/library";

export function App() {
  return <Button>Click me</Button>;
}
```
