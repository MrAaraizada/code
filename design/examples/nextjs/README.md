# Material UI Next.js Examples

This directory contains comprehensive examples of integrating Material UI with Next.js in various configurations.

## Examples Included

- **App Router**: Modern Next.js 13+ app directory structure
- **Pages Router**: Traditional Next.js pages structure  
- **TypeScript**: Full TypeScript integration
- **Server-Side Rendering**: Optimized SSR setup
- **Static Generation**: ISG and SSG examples
- **Pigment CSS**: Zero-runtime CSS-in-JS
- **Tailwind Integration**: Combining Tailwind with Material UI

## Performance Optimizations

- Tree-shaking for minimal bundle size
- Emotion server-side rendering
- CSS variables for dynamic theming
- Lazy loading of components
- Bundle analysis and optimization

## Getting Started

1. Choose the example that matches your needs
2. Install dependencies: 
pm install
3. Run development server: 
pm run dev
4. Build for production: 
pm run build
