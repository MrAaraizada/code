# ActivityIndicator Component

## Overview
A loading indicator component that shows a spinning animation.

## Usage
```tsx
import { ActivityIndicator } from '@design-system/react-native';

<ActivityIndicator size="large" color="#007AFF" />
```

## Props
- `size`: 'small' | 'large' - Size of the indicator
- `color`: string - Color of the indicator
- `animating`: boolean - Whether to show the indicator
