## File Categories for Commits

### Primary Folders (Main Development)
- `apps/` - Main application components and features
- `develop/` - React Native specific development
- `packages/` - Shared packages and utilities
- `library/` - Component library

### Secondary Folders (Supporting)
- `components/` - UI components
- `design/` - Design system files
- `fonts/` - Typography assets
- `pages/` - Documentation pages
- `styles/` - Styling and themes
- `templates/` - Project templates

## Commit Message Patterns

### Component Development
- "feat(develop): add Button component for React Native"
- "feat(library): implement Card component with accessibility"
- "refactor(components): optimize rendering performance"
- "style(develop): update component styling system"

### Platform Services
- "feat(develop/services): add device detection utilities"
- "feat(apps/platform): implement cross-platform bridge"
- "perf(develop): optimize platform-specific performance"
- "fix(develop/services): resolve platform compatibility issues"

### Documentation & Examples
- "docs(develop): add React Native component examples"
- "feat(pages): create component documentation pages"
- "docs(library): update API documentation"
- "example(templates): add React Native project template"

### Testing & Quality
- "test(develop): add component unit tests"
- "test(packages): implement integration tests"
- "ci(build): optimize React Native build process"
- "quality(develop): improve code coverage"

### Configuration & Tooling
- "config(develop): update React Native configuration"
- "build(packages): optimize bundle size"
- "deps(develop): update React Native dependencies"
- "tooling(apps): enhance development workflow"
